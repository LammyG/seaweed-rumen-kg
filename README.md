# Seaweed-Derived Bioactives for Rumen Methane Mitigation
## LLM-Assisted Knowledge Graph (2015–2026)

This repository contains the full data, code, and evaluation materials for:

Okunola, O. (2026). Seaweed-Derived Bioactives for Rumen Methane Mitigation: 
A Systematic Review and LLM-Assisted Knowledge Graph of Efficacy and Microbial 
Mechanisms. Teesside University.

## Contents
- `data/` — corpus, extraction outputs, validation data
- `code/` — Jupyter notebook for full reproduction
- `figures/` — all publication-quality figures (PDF)
- `data/graph/kg_full_126corpus.graphml` — full knowledge graph (open in Gephi)

## Reproduction
1. Install requirements: `pip install -r requirements.txt`
2. Add your DeepSeek API key to Cell 0
3. Run notebook cells in order: 0, 1, 8, 53+
